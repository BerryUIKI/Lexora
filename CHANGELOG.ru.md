## [Не выпущено]

### Добавлено
- Ссылки на официальный сайт в строке заголовка, меню «Справка» и окне «О программе».
- Безопасный возврат на главный экран по значку Lexora без закрытия открытых документов.
- Отображение блочного и встроенного HTML в Markdown, включая HTML внутри заголовков.

### Изменено
- При ручной проверке обновлений сразу отображается состояние процесса, а окно «О программе» остаётся открытым.
- Примечания к обновлению в приложении берутся из словарей Lexora для девяти языков; описание выпуска на GitHub остаётся английским.
- Для актуальной версии отображается зелёная галочка подтверждения.

## [0.1.4] - 2026-08-27

### Добавлено
- Подписанные обновления внутри приложения для Windows, macOS и Linux с прогрессом загрузки и подтверждением установки.
- Ежедневная проверка стабильного канала со случайной задержкой после запуска и возможностью отключения.
- Локализованные примечания к выпуску для всех девяти поддерживаемых языков.

### Изменено
- Перед установкой показывается явное предупреждение, если в открытых вкладках есть несохранённые изменения.
- Версия приложения теперь берётся из `package.json`, а CI сверяет её с Cargo и тегом выпуска.

Предыдущие версии приведены в [полной английской истории изменений](CHANGELOG.md).
