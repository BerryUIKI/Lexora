# 생각에만 집중할 수 있는 순수한 공간

왼쪽에서 마크다운 코드를 쓰고 오른쪽에서 미리보기를 번갈아 볼 필요가 없습니다. 제목, 목록, 굵은 글씨를 입력하면 커서 아래에서 즉시 예쁘게 다듬어집니다.

인플레이스 WYSIWYG · 초고속 전체 검색 · 안전한 자동 저장.

시작 속도 0.4초 미만 순식간에 준비 완료

전체 검색 즉각 반응 폴더 전체 초고속 검색

1행, 1열 · 1,420 단어 · UTF-8 · 저장됨
작성자를 위한 세심한 설계

글쓰기에 꼭 필요한 것만, 방해 요소는 제로

가벼운 메모부터 깊이 있는 논문이나 블로그 초안까지, Taleno는 고요하고 쾌적한 기록 공간을 만듭니다.

3가지 화면 모드

차분하게 글을 읽는 뷰 모드, 직관적인 작성 모드, 세밀하게 문법을 다루는 소스 모드를 단축키 하나로 전환합니다.

원클릭 플러그인 확장

목표 글자수 카운터, 자동 타임스탬프 등 유용한 도구를 내장 플러그인 갤러리에서 손쉽게 추가할 수 있습니다.

편안한 테마 스킨

눈이 편한 라이트/다크 테마는 물론, Dracula, Nord, Catppuccin 등 인기 커뮤니티 테마를 실시간 미리보기로 적용합니다.

9개 국어 지원

운영체제의 언어를 자동으로 감지하며, 언제든 메뉴에서 자유롭게 원하는 언어로 변경할 수 있습니다.

선명한 코드 강조

100여 개 프로그래밍 언어의 구문 강조와 원클릭 코드 복사 버튼을 제공합니다.

다이어그램 및 수식 지원

Mermaid 플로우차트와 시퀀스 다이어그램, KaTeX를 통한 정교한 수학 수식을 실시간으로 렌더링합니다.

폴더 전체 초고속 검색

노트가 아무리 많아도 Ctrl+Shift+F 한 번이면 원하는 단어가 포함된 문서를 순식간에 찾아냅니다.

안심 데이터 보호

저장되지 않은 문서 닫기 시 확인 창을 띄워 실수를 방지하며, 정전 시에도 글이 유실되지 않도록 보호합니다.

손쉬운 드래그 앤 드롭

마크다운 파일을 창 안으로 끌어와 열고, 탭 표시줄에 놓아 새 탭을 만들며, 이미지를 본문에 바로 삽입하세요.

깔끔한 독립 HTML 내보내기

Ctrl+E 단축키로 서식이 완벽히 포함된 단일 웹페이지 파일로 내보내어 동료나 친구에게 손쉽게 공유할 수 있습니다.

기존 마크다운 편집기와 어떻게 다른가요?

많은 편집기는 좌우로 나뉜 2분할 화면을 사용해 답답하거나 앱이 무거워 느려지기 쉽습니다. Taleno는 타이핑하는 즉시 그 자리에서 서식이 적용되며, 1초도 안 되어 바로 실행되고 메모리도 거의 차지하지 않습니다.

기존에 작성해 둔 마크다운 파일을 그대로 쓸 수 있나요?

네, 100% 호환됩니다! Taleno는 표준 마크다운 파일(.md) 형식을 사용합니다. Obsidian, Typora, Notion 등에서 작성한 글을 그대로 열고 저장할 수 있습니다.

내 글이 외부 서버로 유출될 위험은 없나요?

전혀 없습니다. Taleno는 100% 로컬 전용으로 작동하여 모든 문서는 사용자의 컴퓨터에만 안전하게 저장됩니다. 계정 가입도 필요 없으며 인터넷이 없는 곳에서도 완벽히 작동합니다.

테마와 플러그인을 바꿀 수 있나요?

네! 설정에서 기본 라이트/다크 테마 외에도 Dracula, Nord 같은 인기 커뮤니티 스킨을 바로 내려받아 쓸 수 있으며, 유용한 플러그인도 쉽게 추가할 수 있습니다.

Taleno는 무료인가요?

네, Taleno는 오픈 소스(GNU AGPL-3.0)로 누구나 무료로 사용할 수 있으며 유료 결제나 광고, 기능 제한이 일체 없습니다.

Taleno

Taleno는 분할 화면 없이 입력한 자리에서 바로 완성된 서식이 적용되는 무료 로컬 마크다운 리더 및 에디터입니다. 100% 오프라인 개인정보 보호, 빠른 실행, 다양한 테마와 플러그인을 지원합니다. Windows, macOS, Linux 지원.
