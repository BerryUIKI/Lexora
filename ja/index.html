書き手のためのデザイン

書くことに集中できる、快適な機能の数々

日々のメモ、学習記録、本格的な論文執筆まで。Taleno は静かで心地よい空間を提供します。

3つの表示モード

快適に読書できる閲覧モード、直感的な編集モード、構文を細かく整えるソースモードをショートカットで自在に切り替え。

ワンクリック拡張機能

目標文字数カウンターやタイムスタンプ挿入など、便利なプラグインをマーケットからワンクリックで追加可能。

美しいテーマ着せ替え

目に優しいライト・ダークテーマに加え、Dracula、Nord、Catppuccin などの人気テーマをリアルタイムプレビューで適用できます。

9言語ネイティブ対応

OS の言語設定を自動認識。日本語を含む9つの言語に最初から対応しています。

見やすいコードハイライト

100以上のプログラミング言語に対応したシンタックスハイライト。コードブロックのコピーもワンクリックです。

図表＆数式レンダリング

Mermaid によるフローチャートやシーケンス図、KaTeX による数式の美しい組版をリアルタイムに行えます。

フォルダ全体の超高速検索

メモの数が増えても心配無用。Ctrl+Shift+F でワークスペース全体から目的の言葉を瞬時に検索できます。

安心のデータ保護設計

未保存のままウィンドウを閉じる際には確認ダイアログでお知らせ。突然の電源断でもファイルを安全に守ります。

直感的なドラッグ＆ドロップ

ファイルをウィンドウに放り込むだけで閲覧開始。タブバーにドラッグして新規タブ、文章中への画像挿入もスムーズです。

綺麗な HTML への書き出し

Ctrl+E を押すだけで、レイアウトが整った単一の HTML ファイルとしてエクスポート。共有や提出も簡単です。

他の Markdown エディタとの大きな違いは何ですか？

多くのエディタは「左に入力、右にプレビュー」という2画面分割を必要とし、アプリ自体も重くなりがちです。Taleno は打ったその場で綺麗なレイアウトになり、起動も一瞬。画面がすっきりして執筆に没頭できます。

すでに書いた Markdown ファイルはそのまま開けますか？

はい、完全に互換性があります。Taleno は標準的な純粋な .md ファイルを使用します。Obsidian や Typora、Notion などで作成した文書もそのまま開いて編集できます。

ノートの内容が外部サーバーに送信されることはありますか？

一切ありません。すべての文書はお使いのパソコン内にのみ保存されます。アカウント登録も不要で、オフライン環境でも完全にご利用いただけます。

テーマやプラグインは利用できますか？

はい！設定画面からお好みのライト/ダークテーマを選択できるほか、Dracula などのコミュニティテーマや便利なプラグインをワンクリックで導入できます。

利用料金はかかりますか？

完全無料です。オープンソース（GNU AGPL-3.0）として公開されており、有料プランや広告、機能制限などは一切ありません。

Taleno

Taleno は、2分割プレビュー画面を排し、入力したその場で美しく書式が整う無料・高速・完全ローカルの Markdown エディタです。オフライン対応、高速起動、テーマ・プラグイン拡張に対応。Windows・macOS・Linux 対応。
