What makes Lexora different from a typical Markdown editor?

Render-as-you-type with zero split panes, plus native Rust performance — no Electron overhead, instant startup.

Is my data safe?

Documents stay on your device — no cloud involved. Atomic writes and dirty-state tracking survive crashes and quits.

Which Markdown features are supported?

Full GFM support, code syntax highlighting, Mermaid diagrams (flow, sequence, class) and LaTeX math.

Is it free? How can I contribute?

Yes — free and open source under AGPL-3.0. Issues, translations and pull requests are always welcome.
