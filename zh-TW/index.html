按下快捷鍵隨心切換：安享沉浸閱讀的無干擾檢視、隨寫隨排的原位寫作模式，以及完全掌控語法的原始碼檢視。

原生多語言支援

內建 9 種語言介面，自動辨識電腦系統語言，也能在選單中隨時自由切換。

清晰代碼語法高亮

內建百餘種程式語言的彩色語法高亮，附帶語言類型小標籤和一鍵複製代碼區塊功能。

流程圖表與公式渲染

支援 Mermaid 流程圖與時序圖繪製，以及 KaTeX 數學公式即時排版，理工科與學術筆記同樣得心應手。

毫秒級筆記全文搜尋

無論資料夾裡有多少篇文件，按下 Ctrl+Shift+F 瞬間找到關鍵字，文件內尋找替換同樣滑順。

貼心防丟與未儲存提醒

底層原子安全儲存，關閉未儲存文件時主動彈出確認視窗，即使電腦意外斷電也絕不損壞文字。

直覺好用的拖曳互動

把 Markdown 檔案拖進視窗直接閱讀，拖到分頁列新建文件，拖入圖片自動插入對應格式。

一鍵匯出獨立 HTML

隨時按下 Ctrl+E，將當前筆記匯出為排版精緻、無需連線即可直接發送給同事朋友的獨立網頁。

相比其他 Markdown 工具，Taleno 的最大亮點是什麼？

許多筆記工具不是左右雙欄分屏顯得雜亂，就是安裝套件龐大、打字發熱卡頓。Taleno 徹底做到了游標處原位即時渲染，開啟只需零點幾秒，記憶體佔用極低。介面清爽乾淨，讓你全身心投入到思路本身。

我以前在其他軟體裡寫的 Markdown 筆記能直接用嗎？

完全可以！Taleno 嚴格遵循通用的標準 Markdown 規範（.md 檔案）。無論是從 Obsidian、Typora、Notion 匯出的筆記，還是 GitHub 上的文件，都能直接雙擊開啟並儲存，沒有任何私有格式綁定。

我的筆記安全嗎？會不會被上傳到雲端？

絕對安全。Taleno 100% 採用本地優先機制，所有筆記和檔案只存放在你自己的電腦硬碟上，不強制註冊帳號，不收集文件內容，無網路也能完全正常使用。

是否支援更換主題與安裝外掛？

支援！你可以在設定介面自由選擇內建的淺色/深色主題，也可以一鍵下載 Dracula、Nord 等經典社群外觀。想要擴充字數統計、提示區塊等功能，也能在內建的外掛市場隨心挑選。

Taleno 是免費的嗎？

是的，Taleno 基於開源協議完全免費供所有人使用，沒有任何付費門檻、無彈出廣告，也無任何功能限制。
