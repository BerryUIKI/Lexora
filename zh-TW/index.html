核心特色

專注純粹寫作，告別一切干擾

所見即所得打字排版。從文件大綱、多分頁到工作區全文搜尋，所有設計皆為高效沉浸的寫作體驗而生。

三態模式自由切換

一鍵無縫切換閱讀模式（唯讀瀏覽）、寫作模式（原位所見即所得）與源碼模式（行號同步）。

9 種語言國際化支援

內建 9 國在地化語言，依據系統環境全自動辨識，隨時在選單中即時無縫切換。

高效能程式碼高亮

基於 syntect 原生引擎打造，支援上百種程式語言高亮、語言標籤與一鍵複製功能。

Mermaid 圖表與 LaTeX 數學

原生支援流程圖、循序圖、類別圖等 Mermaid 圖表即時渲染，以及 KaTeX 行內/多行數學公式。

Ripgrep 全域全文秒搜

毫秒級工作區全文字快速搜尋（Ctrl+Shift+F）與文件內尋找取代（Ctrl+F/H）。

當機級安全原子儲存

採用暫存檔原子覆寫（.tmp rename）機制與即時中繼狀態追蹤，從根本杜絕資料損壞或遺失。

智慧拖曳互動

拖入檔案立即開啟、拖到分頁列新增分頁、拖入文字區域自動產生規範 Markdown 超連結。

單一檔案獨立 HTML 匯出

一鍵快捷鍵（Ctrl+E）匯出樣式完整、無需外部依賴的獨立離線 HTML 網頁。

Lexora 與傳統 Markdown 編輯器有何不同？

Lexora 採用徹底的原位所見即所得渲染，告別左右分割視窗。打字時游標所在處即時排版，無 Electron 的沉重包袱，冷啟動僅需數百毫秒，帶來極致輕快的原生桌面體驗。

我的文件資料安全嗎？

100% 本機優先。所有文件均完整儲存在您的本機磁碟中，不傳送任何雲端伺服器。配合底層原子寫入機制，即便電腦突發斷電也不會損壞檔案。

支援哪些 Markdown 擴充語法？

完整支援 GitHub Flavored Markdown (GFM)、表格、任務清單、程式碼高亮、Mermaid 圖表（流程圖、循序圖、類別圖等）以及 KaTeX 數學公式渲染。

Lexora 是否免費開源？如何參與貢獻？

是的，Lexora 基於 GNU AGPL-3.0 協議完全免費且開源。歡迎提交 Issue 反饋缺陷、參與多語言翻譯或發起 Pull Request。
