MACOS 說明

macOS 阻擋 Lexora 時如何開啟

目前的 macOS 版本尚未進行程式碼簽署或公證，因此 Gatekeeper 可能提示無法驗證開發者或檢查惡意軟體。

請只在從官方 GitHub Releases 頁面下載且信任該檔案時繼續。 GitHub Releases

  1. 將 Lexora.app 移到應用程式資料夾，然後嘗試開啟一次。
  2. 開啟蘋果選單 → 系統設定 → 隱私權與安全性。
  3. 捲動到安全性，按一下強制打開。此選項會在遭阻擋後保留約一小時。
  4. 依提示完成驗證，然後按一下開啟。之後即可正常啟動。

如果未顯示「強制打開」且你信任該下載，請在終端機中只移除 Lexora 的隔離屬性：

xattr -dr com.apple.quarantine /Applications/Lexora.app

請勿在整個系統停用 Gatekeeper。 查看 Apple 關於開啟未知開發者 App 的說明 →
