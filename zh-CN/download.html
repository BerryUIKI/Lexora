MACOS 帮助

macOS 阻止 Lexora 时如何打开

目前的 macOS 版本尚未进行代码签名或公证，因此 Gatekeeper 可能提示无法验证开发者或无法检查恶意软件。

请仅在从官方 GitHub Releases 页面下载且确认信任该文件时继续。 GitHub Releases

  1. 将 Lexora.app 移到应用程序文件夹，然后尝试打开一次。
  2. 打开苹果菜单 → 系统设置 → 隐私与安全性。
  3. 滚动到安全性，点击仍要打开。此选项会在被阻止后保留约一小时。
  4. 按提示完成验证，然后点击打开。以后即可正常启动。

如果未显示“仍要打开”且你信任该下载，请在终端中仅移除 Lexora 的隔离属性：

xattr -dr com.apple.quarantine /Applications/Lexora.app

请勿在系统范围内禁用 Gatekeeper。 查看 Apple 关于打开未知开发者应用的说明 →
