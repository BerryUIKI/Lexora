## [Unreleased]

### Added
- Initial project scaffold with Tauri 2 + SolidJS + Vite
- Rust backend module structure (commands, models, services, state)
- Frontend component structure (Editor, Sidebar, StatusBar)
- IPC wrappers for Tauri commands and events
- pulldown-cmark Markdown parser with GFM extensions
- syntect code highlighter
- Atomic file write service
- Dark/Light theme with CSS variables and OS preference detection
- Tailwind CSS 4 styling
- TypeScript strict mode configuration
- MIT License
- Project documentation (Architecture, Development, Contributing, Roadmap)
